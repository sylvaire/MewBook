# Milestone — v1.2.0 快速记账与预算预警

**Created:** 2026-05-29
**Status:** Implemented locally
**Priority:** 快速记账增强最高优先级，预算预警系统次优先级

## Goal

把 MewBook 从“能快速记账、能看预算”推进到“更少点击完成日常记账、提前发现预算风险”。

## Scope

### 1. 增强快速记账流

目标是减少高频记账路径中的 1 到 2 次点击，让首页 FAB 和快速记账面板更适合日常重复消费。

可交付能力：

- 常用金额一键按钮，例如 `9.9`、`12`、`25`，并预留后续按用户历史动态排序的空间。
- 常用场景/分类一键入口，例如午餐、通勤等；只展示当前账本中可用的分类候选。
- 上次输入记忆：按记录类型和时间段自动预填账户、分类、金额或备注建议。
- 双击首页 FAB 直接进入快捷记账；保留单击完整记账、长按快捷菜单等现有行为。
- 快速记账保存成功后更新本地记忆，不上传、不暴露隐私数据。

### 2. 预算提醒升级为预警系统

目标是从“事后看预算”升级为“提前干预支出风险”，并保持提醒克制、可解释、不会打扰。

可交付能力：

- 总预算和分类预算使用率阈值提醒：50%、80%、100%。
- 月末预测超支：基于当前周期日均支出和剩余天数估算。
- 分类预算异常波动提示：和上周或上月同类支出对比，识别显著升高。
- 预算页展示可解释预警摘要，作为 inline 状态呈现而不重复弹窗刷屏。
- 无预算、数据不足或历史样本不足时稳定降级为不提示。

## Acceptance Criteria

1. 用户可以通过快速记账面板的一键金额或场景入口完成一笔记录，且比完整记账少至少一步。
2. 用户在相近时间段再次打开快速记账时，账户和分类可根据最近成功记录自动预填。
3. 双击首页 FAB 可直接打开快捷记账入口，不破坏单击、长按和当前底部导航行为。
4. 预算达到 50%、80%、100% 阈值时，应用能给出明确但不重复刷屏的提醒状态。
5. 有足够数据时，应用能预测本月是否可能超支，并展示计算依据。
6. 分类支出出现明显环比异常时，应用能提示对应分类、变化幅度和参考周期。
7. 所有新策略具备可单元测试的 policy/calculator 层，Compose UI 只负责展示和触发。
8. 快速记账和预算预警都遵守现有触感反馈、分类可见性、账本/账户默认值和本地数据安全约束。

## Proposed Phases

| Phase | Name | Outcome |
|-------|------|---------|
| 8 | 快速记账提速 | 一键金额/场景、时间段记忆、双击 FAB 快捷入口 |
| 9 | 预算预警系统 | 阈值提醒、月末预测、分类异常波动提示 |

## Out of Scope

| Feature | Reason |
|---------|--------|
| 云端个性化推荐 | 当前应用定位是本地优先，v1.2.0 只做本地历史记忆 |
| 复杂机器学习模型 | 预算预警先使用可解释、可测试的规则算法 |
| 推送通知 | 先做应用内预警，避免权限、打扰频率和后台策略复杂化 |
| 自定义任意提醒规则编辑器 | v1.2.0 先提供默认阈值和稳定体验 |

## Risks

- 双击 FAB 可能和单击 FAB 产生手势歧义，需要清晰阈值和防误触策略。
- 常用金额/分类推荐如果过多，会让快捷面板变复杂，需要严格控制数量。
- 预算预警需要避免重复提醒和误报，否则会降低信任感。
- 异常波动依赖历史数据，数据不足时必须明确降级为“不展示”。

## Verification Plan

- 单元测试：快速记账记忆策略、金额/场景候选排序、FAB 点击策略、预算阈值、月末预测、异常波动计算。
- Compose/UI 检查：快速面板触摸目标、底部安全区、空状态、触感反馈开关覆盖。
- 集成验证：保存快速记账后首页列表、预算统计、分类统计同步更新。
- 回归验证：`testDebugUnitTest`、`:app:lintDebug`、`:app:assembleDebug`。

## Implementation Notes

- 常用金额第一版采用固定默认值 `9.9`、`12`、`25` 加历史快速记账金额混合策略。
- 双击 FAB 优先使用最近/记忆的记录类型，无记忆时默认快速支出。
- 预算预警第一版采用预算页内 inline 提示，不新增推送通知、弹窗刷屏或持久已读状态。
