# 主页记账项左滑操作设计

## 背景与目标

MewBook 主页的记账项当前通过 `RecordItem` 展示，点击条目进入记录详情；编辑和删除能力已存在于详情与编辑流程中。此次改动在主页记账项上增加左滑操作入口，让用户能更快地编辑或删除记录，同时保持现有黏土风格、列表排版和数据安全策略。

目标：

- 左滑主页记账项后露出“编辑”和“删除”两个操作按钮。
- 滑动过程跟手、可中断，释放后自然吸附或回弹。
- 操作区与当前黏土卡片、浅色/深色主题一致。
- 卡片内容在滑动时不压缩、不重排，避免分类、备注和金额跳动。
- 删除必须点击按钮并经过现有确认弹窗，不允许滑到底直接删除。

不在范围内：

- 不改变统计页或其他页面的 `RecordItem` 交互。
- 不改变记录编辑表单、删除仓储、回收站或数据库结构。
- 不新增右滑操作、批量操作或手势教学。

## 交互设计

### 基本手势

- 仅支持从右向左揭示操作区。
- 操作区完整展开宽度约为 `144dp`。
- 拖动期间卡片水平位移实时跟随手指，不播放独立位移动画。
- 释放后根据位置和速度吸附至关闭或完整展开状态。
- 吸附与回弹使用自然的 Material 动效，目标时长约 `220–280ms`。
- 滑到底不会触发编辑或删除，任何动作都必须点击对应按钮。
- 横向手势达到合理阈值后才开始揭示，降低与 `LazyColumn` 纵向滚动的冲突。

### 展开状态

- 同一时间最多展开一条记录。
- 展开另一条时，上一条平滑收起。
- 点击已展开卡片的主体时先收起；卡片关闭状态下点击仍打开记录详情。
- 列表数据刷新、进入编辑流程或开始删除流程时收起当前操作区。

### 编辑

- 点击“编辑”后立即收起条目。
- 复用 `HomeViewModel.editRecordFromDetail(record)` 进入现有完整编辑表单。
- 不增加中间详情页或新的编辑界面。

### 删除

- 点击“删除”后立即收起条目并打开现有删除确认弹窗。
- 弹窗继续说明记录可在 30 天内从回收站找回。
- 用户确认后调用现有 `deleteRecord(id)`。
- 用户取消时不改变数据。
- 左滑距离或速度无论多大，都不能绕过确认弹窗。

## 视觉设计

采用已确认的“双黏土按钮”方案：

- 操作区位于卡片背后，编辑在左、删除在最右。
- 两个按钮均使用独立圆角容器、柔和内高光和轻量阴影。
- 编辑按钮使用主题派生的温暖辅助色；删除按钮使用 Material 语义错误色的柔和容器色。
- 图标采用项目已有的 Material 图标体系，并配合“编辑”“删除”文字，避免仅靠颜色或图标传达含义。
- 每个按钮的有效触控区域不小于 `48dp`。
- 按钮揭示时根据滑动进度做轻微缩放与淡入；卡片主体只做水平位移。
- 系统减少动画时，缩短或取消非必要的淡入缩放，但保留直接的位置反馈。

### 排版约束

- 卡片保持现有高度、圆角、阴影和内边距。
- 分类图标、分类名称、备注和金额作为一个整体移动。
- 滑动过程中不重新测量为更窄的卡片内容宽度。
- 长备注继续使用既有截断规则；大金额保持单行，不与操作按钮共享布局宽度。
- 操作背景裁切到与卡片一致的外轮廓，避免圆角边缘漏色。

## 组件与状态边界

### `RecordItem`

`RecordItem` 保持为可复用的记录内容卡片，不直接加入主页专属的编辑、删除或全局展开状态。这样统计页等既有调用方不会获得未请求的手势行为。

### 主页可滑动包装组件

在主页 UI 范围内新增可滑动包装组件，职责包括：

- 渲染编辑/删除操作背景。
- 管理单条记录的打开、关闭和拖动状态。
- 将编辑、删除和卡片点击事件转发给 `HomeRecordList`。
- 提供按钮的点击语义、内容描述和触感反馈。

包装组件不访问 ViewModel、Repository 或数据库。

### `HomeRecordList`

`HomeRecordList` 持有当前展开记录的 ID，并向各包装组件传递是否展开及状态变更回调。记录 ID 作为稳定标识，避免列表复用或重排时把展开状态错误地带到另一条记录。

当当前展开的记录从输入列表中消失时，展开 ID 自动清空。发起编辑或删除前也清空展开 ID。

### `HomeScreen`

`HomeScreen` 继续负责调用 ViewModel 和展示删除确认弹窗：

- 编辑回调调用 `editRecordFromDetail(record)`。
- 删除回调只设置待删除 ID 并打开确认弹窗。
- 确认按钮调用 `deleteRecord(id)`。
- 取消按钮清理待删除状态，不执行删除。

## 数据流

编辑流程：

1. 用户左滑记录并点击“编辑”。
2. 包装组件关闭操作区并回调记录对象。
3. `HomeRecordList` 清理展开 ID。
4. `HomeScreen` 调用现有 ViewModel 编辑入口。
5. 现有完整编辑表单打开。

删除流程：

1. 用户左滑记录并点击“删除”。
2. 包装组件关闭操作区并回调记录 ID。
3. `HomeRecordList` 清理展开 ID。
4. `HomeScreen` 设置待删除 ID 并显示现有确认弹窗。
5. 用户确认后，ViewModel 将记录移入 30 天回收站；用户取消则不修改数据。

## 异常与边界情况

- 若操作前记录已从当前列表消失，清除展开状态并忽略已失效动作。
- 列表快速刷新、筛选变化或周期切换后，不保留指向不存在记录的展开状态。
- 快速连续滑动不同条目时，只保留最后一条的展开请求。
- 动画可被新的拖动、点击或列表状态变化中断，不阻塞输入。
- 浅色和深色主题均通过 Material 及项目语义色取色，不在组件中写死最终颜色。
- 大字体下按钮图标和文字保持垂直居中；操作区不参与卡片主体测量，因此不会挤压金额或备注。
- 触感反馈沿用现有设置；关闭“触感反馈”后不执行震动。

## 测试策略

实现遵循测试先行：

1. 先为单条展开协调策略编写失败单元测试，覆盖打开新条目会替换旧条目、关闭当前条目、记录消失后清理状态。
2. 先为主页动作路由编写失败测试，验证编辑传递正确记录、删除只产生确认请求，不直接调用删除。
3. 对“不允许滑到底自动执行删除”建立可测试的确认规则或 Compose 行为测试；测试必须先观察到预期失败，再实现生产代码。
4. 实现后运行相关定向单测，再运行：

   ```powershell
   .\gradlew.bat testDebugUnitTest
   .\gradlew.bat :app:assembleDebug
   .\gradlew.bat :app:lintDebug
   ```

5. 在模拟器进行手工验证：

   - 浅色和深色主题。
   - 短备注、长备注和空备注。
   - 小额与大额记录。
   - 连续快速滑动不同记录。
   - 滑动后点击编辑、删除、取消删除和确认删除。
   - 纵向滚动与轻微斜向手势。
   - 系统大字体与减少动画设置。

## 验收标准

- 主页记录可左滑露出带图标和文字的编辑、删除黏土按钮。
- 滑动实时跟手，释放后自然吸附或回弹，无明显掉帧或跳动。
- 同时最多一条记录展开。
- 卡片内容在任意滑动进度下不压缩、不重排、不发生金额跳位。
- 编辑按钮打开现有完整编辑表单。
- 删除按钮先展示现有确认弹窗，滑动本身永不删除记录。
- 删除确认后记录进入现有 30 天回收站。
- 统计页及其他复用 `RecordItem` 的页面行为不变。
- 操作按钮满足触控尺寸、内容描述、主题适配和触感反馈要求。
- 相关单测、完整单测、Debug 构建和 lint 均通过。
